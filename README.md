# Dark Souls III — Cemitério das Cinzas

Protótipo de fã, independente e não oficial, inspirado na abertura de **Dark Souls III**. O objetivo desta versão é recriar a sensação de começar no Cemitério das Cinzas: caminho coberto de cinzas, lápides, ruínas góticas, uma fogueira e um guardião bloqueando a passagem.

## Jogar

**[Abrir o jogo no navegador](https://nik0lasdev.github.io/ligt-souls-/)**

O projeto é publicado pelo GitHub Pages usando GitHub Actions.

## Controles

- **W A S D** — mover
- **Mouse** — controlar a câmera
- **Shift** — correr (consome vigor)
- **Espaço** — esquivar
- **Clique esquerdo** ou **F** — atacar
- **Tab** — fixar/liberar alvo
- **E** — descansar na fogueira quando estiver perto
- **Esc** — pausar/retomar
- No celular, use os controles na tela e arraste para orientar a câmera.

## Escopo desta versão

- Área inicial atmosférica inspirada no Cemitério das Cinzas.
- Personagem, inimigos e guardião construídos com geometria procedural original.
- Sistema inicial de vida, vigor, esquiva, ataque, alvo e almas.
- Fogueira que restaura vida e vigor.
- Interface em português e suporte básico a telas móveis.

Este é um projeto de fã feito com código e formas originais. Não inclui modelos, texturas, músicas, sons ou outros arquivos extraídos de Dark Souls III; não é afiliado à FromSoftware nem à Bandai Namco.
